# /spec

Design-intent capture into SPEC.md. Interview, then write.

- One question at a time, each with a recommendation attached — never a menu
  of batched options.
- Settle, in order: what this game is for (the fantasy), the fun bar (what
  must feel good in the first 60 seconds), the pillars, deliberate non-goals,
  open questions.
- Fold answers into SPEC.md's existing sections IN PLACE. No dated layers, no
  changelog, no "Redesign (date)" stacks — rewrite the section.
- Mechanics belong in /outline tickets, not here.
- End by stopping for approval. Do not start /outline in the same turn.
